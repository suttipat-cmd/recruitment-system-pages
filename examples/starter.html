ตัวอย่าง API สำหรับ Vercel ตั้งค่า Environment Variables และสิทธิ์ตารางตาม README ก่อนใช้งาน

GET /api/items — ดึงรายการล่าสุด

POST /api/items — เพิ่มข้อมูล JSON:

{"title":"รายการตัวอย่าง"}

ตัวอย่างนี้ยังไม่มีระบบ Login การเข้าถึงข้อมูลขึ้นอยู่กับ RLS ของเจ้าของ Supabase
