## ผลที่ตรวจแล้ว
| เรื่อง | วิธีตรวจ | ผล |
|---|---|---|
| Build / TypeScript | `npm run build` | ผ่าน |
| ชุดทดสอบ | `npm test` หลังแก้ไข | ผ่าน ดูจำนวนจากผลรันล่าสุด |
| สมัคร / PIN | Automated: PIN เปลี่ยนตามเวลา, การตรวจสิทธิ์, ช่องบังคับ, จำกัดการลอง, token ใช้ครั้งเดียวและหมดอายุ | ผ่านในฐานจำลอง |
| รับสมัครและคำขอ | Automated: สมัครโดยไม่มีคำขอ, คำขอหลายทะเบียน, HR รับเรื่อง, ผูกและปลดเมื่อเปลี่ยนหน่วยงาน, ประวัติ/ยืนยันผลกระทบ | ผ่านในฐานจำลอง |
| สัมภาษณ์ / ทดลองขับ / เริ่มงาน / อบรม | Automated: สัมภาษณ์ผ่านและส่งมอบ, HR กำหนด/บันทึกเริ่มงาน, ไม่มาเริ่มงาน, Coach และสิทธิ์อบรม | ผ่านในฐานจำลอง |
| สำรองและเรียกกลับ | Automated: คงผลสัมภาษณ์เดิมและเปิดรอบใหม่ | ผ่านในฐานจำลอง |
| บทบาทและสิทธิ์ | Automated: HR, Admin, Supervisor ตามหน่วยงานและสิทธิ์ทุกหน่วยงาน, Coach, การปฏิเสธข้ามหน่วยงานและข้อมูลส่วนบุคคล | ผ่านในฐานจำลอง |
| KPI | Automated: เคสรับทัน 14 วัน, cohort 90 วันและกรณีลาออก/ขอบเขตวัน | ผ่านในเคสที่ทดสอบ ยังไม่ครอบคลุมทุกกรณีขอบเวลา |
| เอกสาร | Automated: ชนิด/ขนาดไฟล์, bridge ปลอม, ตรวจสิทธิ์, upload ซ้ำ, ป้องกันเข้าถึงโฟลเดอร์ผิด | ผ่านด้วย bridge และ Drive จำลอง |
| ตารางผู้สมัคร | UI: ค้นหาไม่พบ, ข้อความผลว่าง, ล้างตัวกรองและเปิดรายการ | ผ่านด้วยข้อมูลสมมติ |
| วันที่พิมพ์ผิด | UI: พิมพ์ 00/01/2026, ย้ายโฟกัส, กดค้นหา; แก้เป็นวันถูกต้องและเลือกผ่านปฏิทิน | พบค่าถูกล้างก่อนแก้ไข; หลังแก้ไขคงค่า แจ้งภาษาไทย และวันถูกต้องใช้งานต่อได้ |

## ยังไม่ได้ตรวจ
- End-to-end ทุกขั้นตอนบนเบราว์เซอร์ครบทุกบทบาทและทุกสถานะ; ชุดทดสอบฐานข้อมูลไม่เท่ากับการทดสอบ UI ครบทุกเส้นทาง
- ภาพรวมและปุ่มทุกหน้าที่ขนาดหน้าจอมือถือจริง รวม keyboard, screen reader และเบราว์เซอร์หลายชนิด
- อัปโหลด/เปิด/ดาวน์โหลด JPG, PNG, PDF ผ่าน Google Drive และ Apps Script จริงตามสิทธิ์แต่ละบทบาท
- ทดสอบภาวะเครือข่ายขาด, หน้าเปิดค้าง, session หมดอายุ, การใช้งานพร้อมกัน และตรวจ KPI 14 วัน ณ จุดขอบเวลาในระบบจริง
- ทดสอบกับข้อมูลจริงหรือเขียนข้อมูลทดลองลงฐานใช้งานจริง
